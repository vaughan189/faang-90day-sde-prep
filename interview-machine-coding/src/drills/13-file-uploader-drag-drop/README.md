# 13. File Uploader with Drag-and-Drop (Day 24)

> **Category**: Machine Coding Drill  
> **Target Companies**: Dropbox, Atlassian, Google  
> **Time Target**: 45 Minutes  

## Objective
File uploader widget with drag-and-drop dropzone, simulated chunk upload progress bars, and retry capability.

## Senior Interview Rubric & Requirements
- [ ] Drag and drop target events: onDragOver, onDragEnter, onDragLeave, onDrop
- [ ] File validation: check allowed file types (e.g. image/png, application/pdf) and max file size
- [ ] File list displaying name, formatted size (KB/MB), and status
- [ ] Simulated upload progress bar (0% to 100%) for each file
- [ ] Cancel upload / remove file button with retry mechanism on simulated error

## Practice Guide
1. Start the countdown timer in the top header.
2. Write your implementation inside `FileUploaderDragDropDrill.tsx`.
3. Test all edge cases and keyboard interactions.
4. Check off each requirement as you finish.
