# 15. Month 1 Benchmark: Data Table (Day 29)

> **Category**: Timed Mock Benchmark  
> **Target Companies**: Stripe, Datadog, Snowflake  
> **Time Target**: 60 Minutes  

## Objective
Month 1 Benchmark drill: Build a production-grade data table with multi-column sorting, multi-field search filtering, pagination, and select-all checkboxes in 60 minutes.

## Senior Interview Rubric & Requirements
- [ ] Multi-column sorting (ascending, descending, neutral sort order)
- [ ] Search filter across multiple text columns with instant query updates
- [ ] Pagination controls: page number buttons, previous/next, items per page dropdown
- [ ] Select-all checkbox with indeterminate state for row selection
- [ ] Empty query and zero results state UI
- [ ] Clean TypeScript interfaces for generic column definitions

## Practice Guide
1. Start the countdown timer in the top header.
2. Write your implementation inside `SearchableSortableDataTableDrill.tsx`.
3. Test all edge cases and keyboard interactions.
4. Check off each requirement as you finish.
