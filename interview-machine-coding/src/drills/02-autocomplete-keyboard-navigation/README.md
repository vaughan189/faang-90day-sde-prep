# 02. Autocomplete Keyboard Navigation (Day 5)

> **Category**: Machine Coding Drill  
> **Target Companies**: Google, Uber, Amazon  
> **Time Target**: 45 Minutes  

## Objective
Search autocomplete dropdown with full keyboard navigation: ArrowUp, ArrowDown, Enter selection, and Escape to close.

## Senior Interview Rubric & Requirements
- [ ] ArrowDown & ArrowUp cycles through suggested items with visual active focus state
- [ ] Enter key selects highlighted item and populates search input
- [ ] Escape key closes suggestions list without selecting
- [ ] Auto-scroll selected item into view if dropdown overflows (scrollIntoView)
- [ ] WAI-ARIA Combobox pattern: role="combobox", aria-autocomplete="list", aria-expanded
