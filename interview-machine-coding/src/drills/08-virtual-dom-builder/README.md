# 08. Virtual DOM Builder & Renderer (Day 15)

> **Category**: Machine Coding Drill  
> **Target Companies**: Meta, Google, Atlassian  
> **Time Target**: 45 Minutes  

## Objective
Custom virtualized DOM builder or JSX element converter (h / createElement and render to real DOM).

## Senior Interview Rubric & Requirements
- [ ] Implement h(tag, props, ...children) returning VNode object representation
- [ ] Implement render(vnode) transforming VNode tree into native browser DOM elements
- [ ] Handle attributes: className, style object, and onClick event listeners
- [ ] Handle primitive text children and nested element arrays
- [ ] Mount custom VNode tree into container element

## Practice Guide
1. Start the countdown timer in the top header.
2. Write your implementation inside `VirtualDomBuilderDrill.tsx`.
3. Test all edge cases and keyboard interactions.
4. Check off each requirement as you finish.
