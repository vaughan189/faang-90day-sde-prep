# 09. Nested Comments Thread (Day 17)

> **Category**: Machine Coding Drill  
> **Target Companies**: Reddit, Atlassian, Swiggy  
> **Time Target**: 45 Minutes  

## Objective
Recursive nested comments discussion thread with collapsible replies, voting, and reply inputs.

## Senior Interview Rubric & Requirements
- [ ] Recursive component tree rendering for comments and replies
- [ ] Collapse / expand thread subtrees with visual branch indentation lines
- [ ] Add reply to comment at arbitrary nesting depth
- [ ] Score mutation (Upvote / Downvote toggle)
- [ ] Immutable state tree updates when adding comments

## Practice Guide
1. Start the countdown timer in the top header.
2. Write your implementation inside `NestedCommentsThreadDrill.tsx`.
3. Test all edge cases and keyboard interactions.
4. Check off each requirement as you finish.
