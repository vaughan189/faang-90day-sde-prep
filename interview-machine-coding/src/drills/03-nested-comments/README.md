# 03. Nested Comments / Reddit Thread

> **Target Companies**: Reddit, Atlassian, Swiggy  
> **Time Target**: 45 mins  

## Objective
Evaluated at Reddit, Atlassian, and Swiggy. Features recursive tree rendering, arbitrary depth replies, collapse/expand branches, and upvote/downvote mutations.

## Senior Interview Rubric & Requirements
- [ ] Recursive component tree rendering for comments and replies
- [ ] Collapse / expand thread subtrees with visual branch line
- [ ] Add reply to comment at arbitrary depth
- [ ] Score mutation (Upvote / Downvote toggle)
- [ ] Immutably update state tree when adding or editing nested comments
- [ ] Timestamp / Relative time formatting

4. Check off each requirement as you finish.
