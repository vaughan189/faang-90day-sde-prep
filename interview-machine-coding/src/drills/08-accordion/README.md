# 08. Accessible Accordion

> **Target Companies**: Atlassian, Apple, Salesforce  
> **Time Target**: 45 mins  

## Objective
Evaluated at Atlassian, Apple, and Salesforce. Features single-expand vs multi-expand toggle, smooth height animation, and ArrowDown/ArrowUp keyboard focus traversal.

## Senior Interview Rubric & Requirements
- [ ] ARIA semantics: aria-expanded, aria-controls, role="region"
- [ ] Single-expand mode (accordion) vs multi-expand mode (collapsible panels)
- [ ] Keyboard traversal: ArrowDown / ArrowUp moves focus between headers, Home / End
- [ ] Smooth CSS height transition without layout jank
- [ ] Disabled section support

## Practice Guide
1. Start the countdown timer in the top header.
2. Write your implementation inside `AccordionDrill.tsx`.
3. Test all edge cases and keyboard interactions.
4. Check off each requirement as you finish.
