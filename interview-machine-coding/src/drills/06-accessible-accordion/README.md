# 06. Accessible Accordion (Day 13)

> **Category**: Machine Coding Drill  
> **Target Companies**: Atlassian, Apple, Salesforce  
> **Time Target**: 45 Minutes  

## Objective
Accessible collapsible accordion with single-expand vs multi-expand mode and keyboard arrow traversal.

## Senior Interview Rubric & Requirements
- [ ] ARIA semantics: aria-expanded, aria-controls, role="region"
- [ ] Single-expand mode vs multi-expand collapsible panels
- [ ] Keyboard traversal: ArrowDown / ArrowUp moves focus between accordion headers
- [ ] Home / End keys move to first / last header
- [ ] Smooth height transition animation

## Practice Guide
1. Start the countdown timer in the top header.
2. Write your implementation inside `AccessibleAccordionDrill.tsx`.
3. Test all edge cases and keyboard interactions.
4. Check off each requirement as you finish.
